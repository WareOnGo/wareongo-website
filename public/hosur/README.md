# Hosur ad-page map

Supplied in `handover-2026-10-14/wireframes/assets/`, rendered with MapLibre,
OpenFreeMap's Liberty style and OpenStreetMap data. The three WebP images are
used unchanged at their 2× pixel sizes: desktop 2520×1080, tablet 1620×1080,
mobile 720×720. Marker positions are in the handoff and the code-owned
`src/data/micromarket-ad-layouts/hosur.json` profile.

The shared map component displays this attribution below the image:
“© OpenFreeMap © OpenMapTiles, data © OpenStreetMap contributors”.
